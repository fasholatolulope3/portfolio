About

Full-stack engineer, from database to deployment.

I'm a Software Engineer with a Computer Science background and three years of hands-on experience designing and shipping production software. My work spans both ends of the stack — Node.js/Express and PHP/Laravel APIs on the backend, React, Next.js, Vue.js, and React Native on the front end — backed by relational and document databases including PostgreSQL, MongoDB, and MySQL.

I've built and deployed a fintech remittance platform and a multi-role delivery marketplace, each with real payment processing, authentication, role-based access control, and admin tooling running in production. I care about systems that stay maintainable as they grow — clear API boundaries, sensible data models, and code another engineer can pick up without a walkthrough.

Alongside client and product work, I've led technical support for AI training workshops at academic conferences in Nigeria — experience that sharpened how I communicate technical detail clearly and work well under pressure.
